# Affinity Photo 2 - 이미지 라운드 엣지(둥근 모서리) 처리 방법

## Rounded Rectangle + 클리핑 마스크 방식

1. **Rounded Rectangle Tool** 선택
2. 상단 컨텍스트 바에서 **Corner Radius** 설정 (예: 30px)
3. 캔버스 위에 도형 생성 — 정확한 크기 맞추는 법:
   - **방법 A:** 캔버스를 클릭(드래그 X) → 크기 입력 다이얼로그에서 이미지와 동일한 W × H 입력
   - **방법 B:** 대충 그린 뒤 **Transform 패널** (`View → Studio → Transform`)에서 X: 0, Y: 0, W, H를 직접 수치 입력
4. 도형과 이미지를 정렬 (둘 다 선택 → 가운데 정렬)
5. **레이어 패널**에서 이미지 레이어를 라운드 사각형 레이어 안으로 드래그 → 클리핑 마스크 적용
6. 모서리가 둥글게 잘린 결과 확인 — 코너 값은 나중에도 수정 가능

## 활용 예시

- GitHub README 헤더 이미지에 라운드 코너 적용 (30px radius)
- 투명 배경 PNG/WebP로 내보내기 시 둥근 모서리 유지
