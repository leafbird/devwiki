## yazi cheat sheet

터미널 파일 매니저. https://yazi-rs.github.io

### 시작 / 종료

	q             종료 (cwd 변경 반영)
	Q             종료 (cwd 변경 무시)
	Ctrl+z        yazi를 suspend → 셸 작업 → fg로 복귀 ⭐

> **셸 명령 실행 팁:** `;`(비동기)이나 `:`(블로킹)도 있지만, 출력을 보면서 작업하려면  
> `Ctrl+z`로 suspend 후 셸에서 작업하고 `fg`로 돌아오는 게 가장 편하다.

### 네비게이션

	h / l         상위 / 하위 디렉토리
	j / k         아래 / 위 항목
	g g           목록 맨 위
	G             목록 맨 아래
	H             이전 디렉토리 (뒤로)
	L             다음 디렉토리 (앞으로)
	Ctrl+u / d    반 페이지 위 / 아래
	Ctrl+b / f    한 페이지 위 / 아래
	~             홈 디렉토리 (또는 F1: 도움말)

### 빠른 이동 (zoxide / fzf)

	Z             zoxide 점프 (자주 가는 경로)
	z             fzf로 디렉토리 검색 / 파일 reveal

> yazi로 디렉토리를 탐색하면 자동으로 zoxide DB에 기록된다.

### 파일 작업

	o / Enter     파일 열기 (기본 앱)
	O / S-Enter   파일 열기 (앱 선택)
	y             복사 (yank)
	x             잘라내기 (cut)
	Y / X         yank 취소
	p             붙여넣기
	P             붙여넣기 (덮어쓰기)
	d             삭제 (휴지통)
	D             영구 삭제
	a             새 파일/디렉토리 생성 (끝에 /로 디렉토리)
	r             이름 변경
	-             심볼릭 링크 (절대경로)
	_             심볼릭 링크 (상대경로)

### 선택

	Space         현재 항목 선택/해제
	v             비주얼 모드 (선택)
	V             비주얼 모드 (해제)
	Ctrl+a        전체 선택
	Ctrl+r        선택 반전
	Esc           선택 해제 / 필터·검색 취소

### 검색 & 필터

	/             다음 파일 찾기
	?             이전 파일 찾기
	n / N         다음 / 이전 검색 결과
	f             필터 (패턴으로 목록 필터링)
	s             fd로 파일명 검색 (재귀)
	S             rg로 파일 내용 검색 (재귀)
	Ctrl+s        검색 취소

### 탭

	t             새 탭
	1 ~ 9         n번 탭으로 이동
	[ / ]         이전 / 다음 탭
	Ctrl+c        탭 닫기

> **탭 간 파일 복사:** `y`로 yank → 다른 탭으로 이동 → `p`로 paste

### 미리보기 & 정보

	Tab           파일 정보 (spot)
	K / J         미리보기 5줄 위 / 아래 스크롤

### 정렬

	, → m / M     수정일 (정순/역순)
	, → b / B     생성일 (정순/역순)
	, → e / E     확장자 (정순/역순)
	, → a / A     알파벳 (정순/역순)
	, → n / N     자연 정렬 (정순/역순)
	, → s / S     크기 (정순/역순)
	, → r         랜덤

### 경로 복사

	c → c         파일 경로 복사
	c → d         디렉토리 경로 복사
	c → f         파일명 복사
	c → n         파일명 (확장자 제외) 복사

### 셸 명령

	;             셸 명령 실행 (비동기, 출력 안 보임)
	:             셸 명령 실행 (블로킹, 끝나면 즉시 복귀)

> `:` 블로킹 모드는 명령이 끝나는 즉시 yazi로 돌아오기 때문에  
> `ls` 같은 빠른 명령은 결과가 보이기도 전에 화면이 돌아온다.  
> 출력을 천천히 보면서 작업하려면 `Ctrl+z` suspend를 쓰자.
